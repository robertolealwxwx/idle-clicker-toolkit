# CHANGELOG.md

## [v2.4.1] - 2023-10-15
### Changes:
- Improved performance for `Grandma` auto-upgrades, reducing lag during heavy cookie production.
- Fixed a bug where the `Lucky Cookie` notifications would overlap with the main UI on lower resolution screens.
- Added support for `Candy and Cream` special event clicks.
- Updated the UI color scheme for better visibility during the `Cookie Frenzy` events.

### Fixes:
- Corrected an issue that prevented users from re-enabling the auto-clicker after a manual stop.
- Resolved a crash that could occur when attempting to click during the `Golden Cookie` spawn animation.

## [v2.3.0] - 2023-08-10
### Features:
- Introduced a new `Click Priority` setting allowing users to prioritize specific upgrades when auto-clicking.
- Added a customizable `Click Counter` display to track clicks during gameplay.

### Changes:
- Updated the algorithm for tracking `Cursed Cookies`, improving the efficiency of auto-clicking during curses.
- Improved user feedback with new audio cues when achieving milestones like `Revolution` or `Ascension`.

### Fixes:
- Fixed a bug causing the auto-clicker to sometimes skip upgrades when `Building Queue` was full.
- Resolved a minor layout issue in the settings menu for high-DPI displays.

## [v2.1.0] - 2023-05-05
### Features:
- Added a new mode for auto-clicking during `Seasonal Events`, including special interactions with the `Elder Pledge`.
- Introduced a `Click Delay` setting, allowing users to adjust the speed of clicks during `Cookie Clicker` sessions.

### Changes:
- Improved the detection of `Golden Cookie` appearances to ensure timely clicks.
- Enhanced the overall responsiveness of the UI when navigating through `Achievements` and `Cookie Upgrades`.

### Fixes:
- Fixed a bug that caused app settings to reset after a restart.
- Resolved an issue where the auto-clicker would not function correctly while in desktop mode.
